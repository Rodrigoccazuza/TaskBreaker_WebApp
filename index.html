    🔗 How importing works

    Task Breaker runs entirely in your browser with no server, so it can't do live two-way sync with Notion or Google (those need secure logins a static page can't hold). Instead, import your data any of these ways — it stays on your device, and Pathfinder can then organize it into your categories.

    📄 Upload a file

    CSV or JSON. From Google Sheets: File → Download → CSV. From Notion: ••• → Export → CSV.

    📋 Paste text

    One item per line. Add a date like 2026-10-15 or due: Oct 15 anywhere in the line.

    📊 Published Google Sheet

    In Google Sheets: File → Share → Publish to web (CSV), then paste the link here. Or paste any public CSV link.
